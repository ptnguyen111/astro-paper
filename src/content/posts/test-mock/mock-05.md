### Question 14

> An places four coloured balls (red, blue, green, yellow) into four boxes arranged in a row — box 1, box 2, box 3, box 4. Each box contains exactly one ball, and each colour is used once. Using the clues below, find which colour is in box 2.
>
> Clues:
>
> 1. The red ball is NOT in box 1 or box 3.
> 2. The green ball is in an even-numbered box.
> 3. The blue ball is in box 3.
> 4. The yellow ball is next to the green ball.

**A**. Red \
**B**. Blue \
**C**. Green \
**D**. Yellow

<details name="question-14">
    <summary><i>Show awnswer key</i></summary>    
    <i class="answer-key">Đáp án: **C** — Clue 3: Blue = hộp 3. Clue 1: Red ≠1, ≠3 → Red = hộp 2 hoặc 4. Clue 2: Green = chẵn → Green = hộp 2 hoặc 4. Nếu Red=2, Green=4 → Yellow cạnh Green(4) → Yellow=3 nhưng 3=Blue ✗. Vậy Red=4, Green=2. Hộp 2 = **Green**.</i>
</details>
